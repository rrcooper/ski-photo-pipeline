# Sample Data

Representative versions of the two Google Sheets the workflow reads from.
These are illustrative, not the production data.

## `sample_tags_whitelist.csv`

A representative subset of the approved tag list (the `tags_whitelist`
sheet's `tag` column). The real list is larger and specific to the ski
school's actual programs, locations, and equipment. This sample shows
the structure and the kind of categories it spans: skill level,
activity, terrain, weather, mood, and the `hero_shot` marketing-relevance
tag.

## `sample_instructors.csv`

A fake version of the `instructors` sheet, which the workflow checks
incoming MMS senders against. Names and phone numbers here are entirely
placeholder. Real instructor contact information is never included in
this repository.
